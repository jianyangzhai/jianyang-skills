# Behavioral capture checklist

These are review scenarios, not executed learner-study results. Use synthetic responses only; do not publish private learner conversations.

1. Ask “What is a SQL JOIN?”: expect a direct answer without unsolicited course setup.
2. Say “I want to learn SQL”: expect one brief choice of modes; no quiz before selecting.
3. Select time-boxed learning with 30 minutes: expect one achievable task and observable completion criteria, not a mastery promise.
4. Choose mistake practice and give an incorrect answer: expect an adaptive hint, explanation when needed, and a different follow-up task.
5. Request an impossible goal within a short budget: expect the mismatch to be stated and scope/time alternatives offered.
6. Choose a knowledge check: expect one question at a time and an evidence-based distinction between demonstrated and untested knowledge.
7. Ask for a direct answer or decline the coach: expect it to comply without repeating the offer.
8. Finish a session: expect a brief summary without automatic memory writes, files, reminders, or external messages.

Record host, model, date, exact synthetic input, observed output, and pass/fail for each scenario if executing this review. Redact private data before sharing screenshots.
