# 学习教练 Learning Coach

[English](README.md) · [完整 Skill](SKILL.md)

把“我想学”变成一个可以实际检查的小成果。适合希望有人带练、制定可行路线或查漏补缺的学习者。先给备选，选用后再带练，普通问题不强行变成课程。

```bash
DISABLE_TELEMETRY=1 npx skills add https://github.com/jianyangzhai/jianyang-skills --skill learning-coach
```

## 四种方式

| 方式 | 适用情境 | 如何检查结果 |
|---|---|---|
| 限时入门 | 时间有限，有具体小目标 | 独立完成一个代表性任务 |
| 易错题练习 | 知道概念，实际使用容易错 | 先尝试，按回答给提示，再做变式题 |
| 个人学习路线 | 有目标、期限和投入预算 | 每步有核心任务、完成标准和常见错误 |
| 知识漏洞检查 | 认为自己已掌握，想确认 | 区分已证明掌握、尚未验证和关键缺口 |

四种方式可以单独使用。表达学习意图时，助手只简短推荐一次，由你选择。明确点名本 Skill 就可开始；已有目标、基础和时间的信息不重复询问。随时可以要求直接讲解或示范。

## 安装

使用上方命令，或克隆仓库后把完整 `learning-coach` 文件夹放入宿主的 Skill 目录。复制前检查是否已有同名文件夹。命令关闭安装器遥测；本 Skill 没有额外遥测、外部服务或可执行依赖。指令正文为中文，实际效果依赖宿主和模型。

## 使用例子

- **限时入门**：“用 learning-coach，我会 SELECT，想用 45 分钟学会按月汇总销售额。从一个可验证的小任务开始。”
- **易错题练习**：“用一个容易混淆条件概率的真实场景考我，先让我做，再根据回答提示，最后出变式题。”
- **学习路线**：“两周后我要做五分钟技术分享，每天能练半小时。给我每一步的任务、完成标准和常见错误。”
- **知识漏洞检查**：“我觉得自己懂 attention。一次一道题，检查我会不会解释和应用，最后指出实际暴露的缺口。”

每次结束只简短总结完成了什么、表现如何、下一步做什么。不会因为开始学习就自动写记忆、建文件或创建提醒。

## 证据与限制

这是教学指令工作流，没有学习者实验数据。发布检查可以验证文件、元数据、隐私边界和安装，不能证明教学效果。一次答对不代表长期掌握；不承诺固定时间学会任意技能，也不存在需要开启的隐藏模型模式。

[行为验收清单](CAPTURE-CHECKLIST.md)提供可复核的场景；清单是待验证标准，不是伪造的实测记录。上面的例子是使用建议，不是已完成学习的证据。
