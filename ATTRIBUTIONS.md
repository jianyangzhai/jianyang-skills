# Attributions

`kindle-ebook-preflight` is an original workflow and glue-code implementation maintained by Jianyang Zhai.

It relies on mature external tools rather than reimplementing ebook formats:

- [W3C EPUBCheck](https://github.com/w3c/epubcheck) for EPUB conformance checking.
- [Calibre](https://calibre-ebook.com/) for ebook conversion, metadata inspection, preview, and Kindle thumbnail logic.
- [Amazon Kindle publishing guidance](https://kdp.amazon.com/en_US/help/topic/G200645680) for device-oriented quality review.
